# kinL Codegen API package

This package contains the API client generated by HeyAPI.

## Generate and Update the API client

This package uses OpenAPI types to generate the API client. You need to have the API that runs locally to generate the client. You also need to use Nzoth to have correct types for the API. Follow the [README.md](../../apps/api/README.md) API file to start the project.

Your .env file must contain the correct API URL:

```bash
API_URL=http://localhost:3000
```

To generate the API client, you can use the following command:

```bash
pnpm generate

# or from the root directory

pnpm --filter codegen-api generate
```

This will generate the API client in the `generated` folder.

## Use the API client

Once the API client is generated, you can use it in your project. Here's an example of how to use it:

```typescript
import { apiClient } from '@kinl/codegen-api';

async function getAllLinks() {
  const res = await apiClient.linksControllerGetAllLinks();

  if (res.error) {
    throw res.error;
  }

  return res.data;
}
```
